## 🧪 Learning Method

My learning workflow is based on:

```text
Learn
  ↓
Practice in an authorized lab
  ↓
Understand the result
  ↓
Document the technique
  ↓
Review and improve
  ↓
Publish selected work to GitHub
```

The focus is on **understanding and hands-on practice**, not simply collecting commands.
