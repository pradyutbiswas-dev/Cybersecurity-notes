## 🧪 Practical Labs

### BOLA

Studied how insecure object-level authorization can allow a user to access resources belonging to another user.

Key concepts:

* Object-level authorization
* User/resource ownership
* HTTP status codes
* Access control testing

### Mass Assignment

Studied how automatically binding user-controlled parameters to application objects can expose unintended fields.

Key concepts:

* Parameter manipulation
* Allowlisting fields
* User privilege boundaries
* API request testing
